# Generated raster artwork

Generated WebP images are stored directly in this directory. They were converted from the generated PNG artwork for smaller app assets.

- `life_ledger_logo.webp`: generated brand mark
- `mountain_landscape.webp`: generated mountain background for the balance card
- `icons/food.webp`, `icons/income.webp`, `icons/bills.webp`, `icons/savings.webp`, `icons/shopping.webp`: generated category icons
- `icons/phone_goal.webp`, `icons/plane_goal.webp`, `icons/shield_goal.webp`, `icons/pc_goal.webp`: generated savings-goal icons

Other original PNG/JPEG backgrounds and icons remain available in the companion project ZIP. The current repository includes the main logo, balance-card landscape, and the icons listed above.
