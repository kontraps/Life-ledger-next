# Generated image assets

Copy the generated raster assets from the companion `life-ledger-next.zip` into this folder to restore the exact artwork from the mockup:

- `life_ledger_logo.png`
- `mountain_landscape.png`
- `forest_background.png`
- `mountain_sunset.png`
- `generated_design_sheet.jpg`
- `icons/*.png`

These are image-generated PNG/JPEG assets, not vector icons drawn in code. The current app includes fallback tiles until these image files are added.
